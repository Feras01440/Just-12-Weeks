Scoring: **Strong** = multiple independent recurring-theme rows + at least one verified fact; **Moderate** = recurring rows, single angle; **Thin** = interpretation-heavy or few rows; **Absent** = no public evidence retrievable (honesty row). This matrix is the Gate 0→1 evidence spine and the direct input to [flagship-opportunity-analysis.md](flagship-opportunity-analysis.md).

## Reading rules

Strength scores are about *evidence held*, not truth; "Absent" rows are not weaknesses of the product but of what public data can show (research-limitations Q15). The matrix updates when passive/beta data lands; decision memos cite rows, never bare scores.
