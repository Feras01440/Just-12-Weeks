## 2. Evidence-coding framework (closed set + open slot; code as you file each note)

**Problem codes:** PR-GAP invisible-results gap · PR-COLLAPSE all-or-nothing after disruption · PR-RESTART serial restart pattern · PR-NOGUIDE didn't know what/how to do · PR-SHAME self-blame language · PR-OTHER (open, must be named).
**Help-shape codes (from 11a/11b):** HS-DIRECT wants telling-what-to-do · HS-SHOW wants demonstration · HS-COMPANY wants human/company · HS-SCORE wants records/tracking · HS-MIX (note blend).
**Money codes:** MO-SPENDER real past spend ≥£50 · MO-STRUCTURE paid specifically for structure/plan · MO-WASTE resents past app spend · MO-ZERO no category spend.
**Frame codes:** FR-MOTIVATING fixed term reads as finish line · FR-PRESSURE reads as pressure/cliff · FR-NEUTRAL.
**Recovery codes (E2):** RC-BELIEVED message read as genuine · RC-DISBELIEF suspected manipulation · RC-DOOR-TODAY/RESHAPE/PAUSE door chosen · RC-CONTRAST named it better than apps they've used · RC-BASELINE-QUIT their honest D13 answer was "start something new/quit".
**Concept codes:** CS-1/2/3-FIT statement felt "written for me" · CS-CONFUSED couldn't say what it is · CS-TRACKER heard it as "another tracker" (⚠ positioning failure signal).
Polarity: every code applied with + (supports the linked assumption) or − (contradicts). Rule: a code without a quotable or paraphrasable anchor in the note doesn't get applied.

## 4. Interview synthesis board (run at n≈6 lightly, full at n=done)

Columns: the matrix rows above. Cards: one per coded evidence item, carrying P-code + band + polarity. Lanes per column: **Supports / Contradicts / Complicates**. Board rules: bands visibly marked so age-pattern differences surface (D-006 requires per-band reading); a column with <4 cards is *undersampled*, not "confirmed"; every ⚡ surprise card gets discussed even if it fits no column — surprises are where the product actually improves. Output: per-assumption verdict (supported / mixed / refuted / undersampled) + the three strongest verbatims each way → feeds `validation-evidence.md` and the [decision criteria](decision-criteria.md).
