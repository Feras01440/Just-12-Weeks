# Public Evidence Corpus (Stage 1A)

**Status:** Captured 26 July 2026; **stable-ID migration 26 July 2026** (independent-audit finding H2 — see correction log COR-18). The master row-store of public, lawful, attributable observations behind the Stage-1A evidence documents. **Method (applies to every row):** direct page fetches were blocked by the session's egress proxy, so every row is **search-snippet retrieval of indexed content** from the cited page; quoted excerpts are as-indexed verbatim strings; `[para]` marks tight paraphrase; confidence ratings already discount for snippet-only retrieval. Excerpts are held within fair-quotation limits (≤25 words). **No frequencies are manufactured anywhere**: "recurring review theme" requires ≥3 independent rows and any counted figure carries its source's own counting method. Classifications: verified product fact / public user opinion / recurring review theme / professional interpretation.

**Corpus size (programmatically verified at migration): 227 observations** — E1: 54 · E2: 63 · E3: 58 · E4: 52.

**Stable ID convention (immutable):** every observation carries a permanent ID in its first column — `EV-1nnn` (E1 cluster), `EV-2nnn` (E2), `EV-3nnn` (E3), `EV-4nnn` (E4). IDs never change when rows are reordered, edited or removed; new observations APPEND with the next unused number in their cluster (new clusters start EV-5001+). Retired rows keep their ID with a strikethrough note, never deletion-with-renumber. The check `tools/verify-foundation.py` reports missing, duplicate and unresolved IDs and re-derives the counts above; it must pass before any commit that touches this file or its citers.

**Duplicate-source note:** some observations cite the same source page as another row (marked `dup-src:EV-xxxx` in the Limitation column where detected) — these are distinct observations from a shared page, and never count twice toward a "recurring review theme".
