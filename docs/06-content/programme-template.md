# Programme Template

**Status:** Authoring instrument, v0.1. The fill-in skeleton every new programme starts from — it hard-wires the engine schema, governance record and claims policy into the authoring act itself. (Structural template only; completing it for a real physical/wellbeing programme requires the mandated reviewer before anything ships.)
