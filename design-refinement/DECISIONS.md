# Decisions Made in the Refinement Pass

Each is binding for this phase, reversible before production, and recorded with its trigger for revisiting.

| # | Decision | Reversal trigger |
|---|---|---|
| D-R1 | Atelier is the primary refinement candidate; Quarto is the documented backup; Meridian is discontinued as a complete direction | Real-user testing shows first-sight comprehension of the cloth failing with 60+ participants → promote Quarto |
| D-R2 | Three-destination bottom navigation (Today / The Twelve Weeks / Programme & Support); no Insights, no dashboard | On-device testing shows the administrative hub overloaded → split Programme & Support, never add Insights |
| D-R3 | 200% text re-ranks Today (Begin in first viewport, alternatives visible, why folded to sentence + expansion) rather than scaling proportionally | Screen-reader or switch-access testing shows the fold pattern harms task completion |
| D-R4 | Four-surface texture density system; no texture under running text; dark mode at half alpha | Contrast or visual-noise findings on real OLED/low-res panels |
| D-R5 | Journey legend is permanent (not collapsible) and every state pairs shape + plain name | 200% testing shows the legend cost exceeds its orientation value → collapsible-but-open-by-default |
| D-R6 | First-launch motif: the chosen candidate from the three-way study (recorded in `docs/04-brand/atelier-refinement-report.md`) | First-session comprehension testing |
| D-R7 | Tablet = reading column + material rail; one dominant action; no book spread, no dashboard | iPad multitasking widths prove the rail unaffordable → collapse threshold moves |
| D-R8 | Capacity options restate the action they produce; no default selection | Testing shows choice paralysis → recommend (never preselect) the middle option |
| D-R9 | Bricolage Grotesque + Faustina continue as the working typography; 12px label floor; tabular numerals for timers | On-device rendering (low-res Android) fails the reading test → Faustina falls back to the documented alternative (Literata) |
| D-R10 | Commerce keeps placeholder pricing and the ethical pattern; cancellation path stated beside the price | Platform billing constraints contradict the stated path → copy revises to the honest platform reality |

Explicitly **not** decided in this pass: product name · flagship programme · permanent brand identity · production framework · final typography lock · pricing and monetisation · haptic bindings · any user-research conclusion.
